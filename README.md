Cuss Free Browsing
Cuss Free Browsing is a Chrome extension designed to help users browse the web without encountering offensive language. It scans the webpage content and hides curse words by traversing the DOM elements using recursion.

Features:
Automatically detects and hides bad words in text on any webpage.
Uses a dynamically fetched list of bad words from a hosted API to keep the word list up-to-date.
Published on the Chrome Web Store for easy installation and use.
How it Works:
The extension fetches a list of offensive words from a public API hosted on GitHub Pages. The list is used to identify and replace curse words in the text content on a webpage. The words are replaced with a "****" placeholder, making the browsing experience safer and more family-friendly.

Recent Update:
In the latest update, the list of bad words is now dynamically fetched from an API, rather than being hardcoded, allowing for real-time updates to the word list. This ensures that the extension can continuously improve and keep up with evolving slang and offensive language.

Installation:
Visit the Chrome Web Store link above.
Click Add to Chrome to install the extension.
Once installed, the extension will automatically start filtering bad words across websites.
